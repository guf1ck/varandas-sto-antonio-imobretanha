# Varandas de Stº António · Imobretanha

Public website: https://guf1ck.github.io/varandas-sto-antonio-imobretanha/

Static GitHub Pages edition of the property microsite, with React and Three.js, prerendered Portuguese pages and lazy-loaded 3D interiors.

## Development

Node.js 22.13 or newer. Run `npm ci`, `npm run dev`. Run `npm run check` and `npm run build` before publishing. GitHub Actions deploys `dist` on pushes to `main`.

## Commercial information

Telephone: +351 969 652 575. This edition uses a static availability catalogue; it has no database, administration area or lead submission service. Update both `data/units.json` and `public/catalog.json`, then redeploy when prices or availability change. Reserved apartments remain unavailable for interior visits.

3D views are illustrative. Confirm architectural details, availability and prices with Imobretanha. Project assets are provided for this property website; no reuse licence is granted.
